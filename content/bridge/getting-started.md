Installation and first printer setup for Kinkajou Bridge.

> Content will expand as the Bridge app is scaffolded. For now this page outlines the intended flow.

## Planned steps

1. Install the Windows app (embedded Python runtime; no separate Python install).
2. Open the tray app and add a printer (schema-driven form from the integration).
3. Enable the Streamer.bot adapter and map events to actions.
4. Optionally call the local HTTP API from other tools.
