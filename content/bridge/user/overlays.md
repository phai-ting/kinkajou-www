Show live printer status on stream with hosted **Kinkajou Overlays** as OBS Browser Sources. Bridge supplies the data; the overlay site hosts the widgets and the OBS how-to.

## Quick path

1. Add a printer in Bridge (**Printers**).
2. Open **Details** for that printer and copy a ready-made **Overview** or **Compact** overlay URL (or the printer id).
3. Follow the overlay site’s OBS guide to add a Browser Source — one source per printer if you run several.

## Where to go

| Resource | What you get |
| --- | --- |
| [Bridge overlays catalog](https://overlays.kinkajou.dev/bridge/) | Available overlays, query params, recommended sizes |
| [Configure in OBS](https://overlays.kinkajou.dev/bridge/setup-obs/) | Step-by-step Browser Source setup and multi-printer targeting |

OBS setup details live on the overlay site so they stay in one place. For building your own widgets against Bridge’s API, see [Overlay developer docs](../../overlay-developer/).
